Introduction to Number Systems


A number system is a systematic way of representing numbers. In computing, different number systems are used for various purposes, from internal processing to data representation. The value of a digit in a positional number system depends on the digit itself, its position within the number, and the base (or radix) of the number system.

The main positional number systems we will study are:

Decimal Number System (Base-10): This is the number system we use daily. It has 10 unique digits (0-9). Each position represents a power of 10.

Binary Number System (Base-2): This system is the foundation of all digital computers. It uses only two digits: 0 and 1 (bits). Each position represents a power of 2. Computers use binary because electronic circuits have two stable states: ON (1) or OFF (0).

Octal Number System (Base-8): This system uses eight digits (0-7). Each position represents a power of 8. Octal is often used as a shorthand to represent long binary numbers because three binary digits can be represented by a single octal digit.

Hexadecimal Number System (Base-16): This system uses sixteen digits (0-9 and A-F, where A represents 10, B represents 11, and so on, up to F for 15). Each position represents a power of 16. Hexadecimal is widely used in computer memory addressing and data representation due to its ability to represent four binary digits with a single hexadecimal digit.

The base or radix of a number system indicates the total number of unique digits or symbols used in that system.

2. Binary, Octal, and Hexadecimal to Decimal Conversion


To convert a number from any base to decimal, multiply each digit by its corresponding positional weight (base raised to the power of its position) and sum the results. Positions are counted from right to left, starting with 0.

Example 1: Binary to Decimal
Convert (11011)2 to decimal.

(1 × 24) + (1 × 23) + (0 × 22) + (1 × 21) + (1 × 20)
= (1 × 16) + (1 × 8) + (0 × 4) + (1 × 2) + (1 × 1)
= 16 + 8 + 0 + 2 + 1
= (27)10. So, (11011)2 = (27)10.

Example 2: Octal to Decimal
Convert (347)8 to decimal.

(3 × 82) + (4 × 81) + (7 × 80)
= (3 × 64) + (4 × 8) + (7 × 1)
= 192 + 32 + 7
= (231)10. So, (347)8 = (231)10.

Example 3: Hexadecimal to Decimal
Convert (2A5)16 to decimal.

(2 × 162) + (A × 161) + (5 × 160)
= (2 × 256) + (10 × 16) + (5 × 1)
= 512 + 160 + 5
= (677)10. So, (2A5)16 = (677)10.


3. Binary to Octal and Hexadecimal Conversion


Binary to Octal: Group binary digits in sets of three from right to left, adding leading zeros if necessary. Convert each group of three binary digits into its equivalent octal digit.

Example: Convert (11010111)2 to octal.

Group: 011 010 111 (added a leading zero)
Convert: 3   2   7
So, (11010111)2 = (327)8.

Binary to Hexadecimal: Group binary digits in sets of four from right to left, adding leading zeros if necessary. Convert each group of four binary digits into its equivalent hexadecimal digit.

Example: Convert (11010111)2 to hexadecimal.

Group: 1101 0111
Convert: D   7
So, (11010111)2 = (D7)16.


4. Octal and Hexadecimal to Binary Conversion


Octal to Binary: Convert each octal digit into its 3-bit binary equivalent.

Example: Convert (526)8 to binary.

Convert: 5 (101)   2 (010)   6 (110)
Combine: (101010110)2. So, (526)8 = (101010110)2.

Hexadecimal to Binary: Convert each hexadecimal digit into its 4-bit binary equivalent.

Example: Convert (A3F)16 to binary.

Convert: A (1010)   3 (0011)   F (1111)
Combine: (101000111111)2. So, (A3F)16 = (101000111111)2.


Introduction to Boolean Values, Truth Table, Boolean Expression, and Boolean Function


Boolean Algebra: Named after George Boole, Boolean algebra is a branch of algebra in which the values of the variables are the truth values, true and false, usually denoted 1 and 0 respectively. It is fundamental to the design of digital electronic circuits.

Boolean Values: These are the two possible values in Boolean algebra: True (represented as 1) and False (represented as 0). These correspond to the ON and OFF states of electronic switches.

Truth Table: A truth table is a mathematical table used in logic, specifically in Boolean algebra, to compute the functional values of logical expressions for each combination of input values. It lists all possible input combinations and the corresponding output for a given logical operation or expression.

Boolean Expression: A Boolean expression is an expression formed by combining Boolean variables (which can take values 0 or 1), logical operators (AND, OR, NOT), parentheses, and an equals sign. For example, A + B' is a Boolean expression.

Boolean Function: A Boolean function, also known as a logic function, is an expression that produces a binary output (0 or 1) based on binary inputs. It defines the relationship between input variables and the output of a logic circuit. For a given set of binary variable values, the function can evaluate to either 0 or 1.

Laws of Boolean Algebra


Boolean algebra has several laws that help simplify Boolean expressions and design efficient logic circuits. These laws are similar to algebraic laws but apply to binary variables and logical operations.

Let A, B, and C be Boolean variables (0 or 1).


1. Commutative Laws


These laws state that the order of operands does not affect the result.

AND: A ⋅ B = B ⋅ A

OR: A + B = B + A


2. Associative Laws


These laws state that the grouping of operands does not affect the result when performing the same operation multiple times.

AND: (A ⋅ B) ⋅ C = A ⋅ (B ⋅ C)

OR: (A + B) + C = A + (B + C)


3. Distributive Laws


These laws describe how operations distribute over each other.

AND over OR: A ⋅ (B + C) = (A ⋅ B) + (A ⋅ C)

OR over AND: A + (B ⋅ C) = (A + B) ⋅ (A + C)


4. De Morgan's Laws


De Morgan's laws are crucial for simplifying expressions involving complements (NOT operations).

Law 1: (A + B)' = A' ⋅ B' (The complement of a sum is the product of the complements.)

Law 2: (A ⋅ B)' = A' + B' (The complement of a product is the sum of the complements.)

Other important laws and identities:

Identity Law:

A + 0 = A

A ⋅ 1 = A

Null Law:

A + 1 = 1

A ⋅ 0 = 0

Idempotent Law:

A + A = A

A ⋅ A = A

Complement Law:

A + A' = 1

A ⋅ A' = 0

Involution Law (Double Complement): (A')' = A

Absorption Law:

A + (A ⋅ B) = A

A ⋅ (A + B) = A


Logic Circuits


Logic circuits (or digital circuits) are physical implementations of Boolean functions using logic gates. They are the fundamental components of digital electronics, such as microprocessors, memory, and other digital devices. Designing a logic circuit involves converting a Boolean expression into a diagram using standard logic gate symbols.

Example: Draw a logic circuit for the Boolean expression Y = A ⋅ B + C'.

Here's how to break it down:

Identify the inputs: A, B, C.

Identify the operations: AND (A ⋅ B), NOT (C'), OR (result of A ⋅ B and C').

Draw the gates in sequence:

An AND gate for A and B.

A NOT gate for C.

An OR gate for the output of the AND gate and the output of the NOT gate.

In this circuit, the output of the AND gate is A ⋅ B. The output of the NOT gate is C'. These two outputs then feed into the OR gate, producing the final output Y = A ⋅ B + C'.
